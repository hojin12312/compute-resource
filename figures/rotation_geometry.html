회전의 기하학적 원리 — 차원이 오르면 사영 분포가 걸어갑니다

아래 띠가 이 그림의 본문입니다. 밀도함수는 f(x) ∝ (1 − x²/R²)(D−3)/2 하나이고 D만 바뀝니다 — U자 → 평탄 → 종 모양.
2D · 아크사인 분포 (지수 −1/2)

2차원 회전 (피크 10 → 7.07)

[10, 0] → [7.07, 7.07] · 피크 29.3% 감소
f(x) = 1 / [ π√(10² − x²) ]
두 축이 피크 10을 나눠 7.07이 됩니다. 그런데 사영은 가운데가 얕고 양 끝이 치솟습니다 — 회전각이 균등해서 ±10 근처에 오래 머물기 때문입니다. 양자화에는 최악의 모양입니다.
3D · 균등 분포 (지수 0)

3차원 회전 (피크 10 → 5.77)

[10, 0, 0] → [5.77×3] · 피크 42.3% 감소
f(x) = 1 / 2R = 일정
여기서 지수가 정확히 0이 되어 완전히 평탄한 균등 분포가 됩니다 — 구를 자른 띠의 넓이가 두께에만 비례한다는 아르키메데스 모자상자 정리입니다. 3차원에서만 성립하는 우연입니다.
128D · 푸앵카레–맥스웰–보렐

128차원 회전 (10 → σ 0.884)

[10, 0, …] → σ = 10/√128 = 0.884 · 피크 91.2%↓
(1 − x²/R²)62.5 → N(0, σ²)
128개가 피크를 나눠 가지면 ±10은 사실상 확률 0이 되고 값이 0 근처(±2.65 안에 99.7%)로 몰립니다. 같은 4비트 눈금이 훨씬 촘촘해지는 것 — 이것이 회전이 통하는 이유입니다.
세 띠의 가로축은 같고(±10) 세로 눈금은 패널마다 맞췄습니다 — 높이가 아니라 모양을 보는 그림입니다.
